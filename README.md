## ✨ Возможности

| | |
|---|---|
| ➕ **Создание по входу** | Зашёл в trigger-канал — бот создал комнату и перенёс вас в неё |
| 🎛 **Панель в чате комнаты** | Кнопки, меню и формы в встроенном чате голосового канала, отдельный текстовый канал не нужен |
| 🔒 **Закрыть / открыть** | Запретить подключение новым участникам |
| 👁 **Скрыть / показать** | Спрятать комнату от остальных, находящиеся внутри не вылетают |
| ✏️ **Название** | Переименование через форму |
| 👥 **Лимит участников** | Выбор из списка, от «без лимита» до 99 |
| 👤 **Кик / блок / разблок** | Блокировка хранится в базе и действует, пока владелец её не снимет |
| 👑 **Передача владения** | Вручную или автоматически, когда владелец вышел |
| 📶 **Битрейт** | Выбор с учётом лимита сервера |
| 🗑 **Удаление комнаты** | Одной кнопкой |
| ⚙️ **`/setup`** | Настройка через меню выбора каналов, без ID, плюс **Automatic Setup** |
| 🔁 **Устойчивость** | После перезапуска панели продолжают работать, база сверяется с Discord |
| 🏢 **Много серверов** | У каждого сервера свои настройки |
| 🐳 **Docker + nginx** | Готовый `docker-compose.yml` и `/health` |

## 🧭 Как это работает

```
Пользователь заходит в ➕・Создать комнату
   ├─ бот создаёт один голосовой канал в нужной категории
   ├─ переносит пользователя в комнату
   └─ отправляет панель управления в чат этого голосового канала
Владелец управляет комнатой кнопками панели
Все вышли → таймер удаления → канал удаляется, запись в базе очищается
```

Владелец получает права **только на свою комнату** и никогда не получает Administrator, Manage Guild или Manage Channels. Панелью
может пользоваться только владелец и администраторы сервера, это проверяется при каждом нажатии.

## 🚀 Быстрый старт

1. [Создайте бота](#-создание-бота-в-discord) и скопируйте токен.
2. Поставьте бота любым способом из раздела [Установка](#-установка).
3. Пригласите бота на сервер и выполните `/setup` → **⚡ Automatic Setup**.
4. Зайдите в канал `➕・Создать комнату`.

## 🤖 Создание бота в Discord

1. Откройте [Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен (показывается один раз).
3. Там же в **Privileged Gateway Intents** включите **Server Members Intent** и сохраните. Без него бот не запустится
   (ошибка `4014 Disallowed intent(s)`). Message Content Intent **не нужен**.
4. **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: см. [Права бота](#-права-бота)
5. Откройте сгенерированную ссылку и добавьте бота на сервер.

## 📦 Установка

Требования: **Python 3.12+** (для запуска без Docker) или **Docker** с плагином Compose.

Во всех вариантах сначала подготовьте настройки:

```bash
cp .env.example .env        # Windows (cmd): copy .env.example .env
# откройте .env и впишите DISCORD_TOKEN
```

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

### Docker (любая ОС)

```bash
docker compose up -d --build
docker compose logs -f bot
```

Запустятся два контейнера: `bot` и `nginx`. База лежит в `./data` и переживает пересборку. Проверка: `curl http://localhost/health`.
Если nginx не нужен, удалите сервис `nginx` из `docker-compose.yml`, боту он не требуется, это лишь прокси для `/health`.

### Debian 12 одной командой

```bash
git clone <ваш-репозиторий> voice-bot && cd voice-bot
sudo bash deploy/install_debian12.sh
```

Скрипт поставит Docker (если его нет), спросит токен, создаст `.env`, выставит права на `data` и запустит контейнеры.

**Обновление на сервере:**

```bash
git pull && docker compose up -d --build
```

## ⚙️ Настройка на сервере

Команда `/setup` (только администраторы) открывает панель настройки:

| Кнопка | Что делает |
|---|---|
| ⚡ **Automatic Setup** | Создаёт категорию `🎙 TEMPORARY ROOMS` и канал `➕・Создать комнату`, включает систему |
| 🎙 **Trigger** | Выбор канала, вход в который создаёт комнату |
| 📁 **Category** | Категория, в которой создаются комнаты |
| 👥 **Default Limit** | Лимит участников по умолчанию |
| ⏱ **Delete Delay** | Через сколько секунд удалять пустую комнату |
| ✏️ **Room Name** | Шаблон названия, `{user}` подставляет ник владельца |
| 👑 **Auto Transfer** | Передавать владение, когда владелец вышел |
| 🟢 / 🔴 **Enable / Disable** | Включить или выключить систему |

Если у бота не хватает прав, в панели показывается предупреждение со списком недостающих.

## 🎛 Панель комнаты

Панель появляется в чате голосового канала сразу после создания комнаты и обновляется на месте.

| Кнопка | Действие |
|---|---|
| 🔒 Закрыть / 🔓 Открыть | Запретить или разрешить подключение |
| 👁 Скрыть / 👀 Показать | Скрыть комнату от остальных |
| ✏️ Название | Переименовать комнату |
| 👥 Лимит | Выбрать лимит участников |
| 👑 Владелец | Передать владение другому участнику |
| 👤 Участники | Кик, блокировка, список заблокированных и разблокировка |
| ⚙️ Настройки | Битрейт и удаление комнаты |

> Discord разрешает менять название канала не чаще 2 раз за 10 минут. Бот ждёт до 15 секунд и сообщает, если лимит исчерпан.

## 🔧 Конфигурация

Переменные окружения (файл `.env`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_TOKEN` | — | Токен бота (обязательно) |
| `DATABASE_URL` | `sqlite+aiosqlite:///./data/bot.db` | Строка подключения к базе |
| `LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `HEALTH_HOST` | `127.0.0.1` | Адрес health-эндпоинта (в Docker `0.0.0.0`) |
| `HEALTH_PORT` | `8080` | Порт health-эндпоинта, `0` отключает его |

## 🔑 Права бота

Права должны быть у **роли бота** на сервере (Administrator не обязателен).

| Право (RU) | Permission (EN) | Зачем |
|---|---|---|
| Просмотр каналов | View Channels | Видеть категорию и комнаты |
| Управление каналами | Manage Channels | Создавать, удалять и менять каналы |
| Управление ролями | Manage Roles | Выставлять права на каналах (закрыть, скрыть, блок) |
| Подключаться | Connect | Права самого бота на комнате |
| Перемещать участников | Move Members | Переносить в комнату, кик и блок |
| Отправлять сообщения | Send Messages | Отправлять панель в чат комнаты |
| Встраивать ссылки | Embed Links | Панель это embed |
| Читать историю сообщений | Read Message History | Редактировать панель после перезапуска |

Если прав не хватает, комната не создаётся, а в логе появляется `bot lacks permissions [...]`.

## 🏗 Архитектура

```
discord_voice_bot/
├── bot.py                  # запуск, сборка сервисов, /health
├── config.py               # чтение .env
├── cogs/
│   ├── voice.py            # события голоса и удаления каналов
│   ├── setup.py            # /setup
│   └── admin.py            # /voice_admin
├── services/
│   ├── voice_service.py    # жизненный цикл комнат, действия владельца, сверка
│   ├── channel_service.py  # создание/удаление каналов, панель
│   ├── permission_service.py  # все overwrites в одном месте
│   └── ownership_service.py   # передача владения
├── views/                  # панель, меню, формы, /setup
├── database/               # модели, репозитории, миграции (SQLAlchemy async)
├── utils/                  # блокировки, проверки прав, логирование
├── deploy/install_debian12.sh
├── nginx/default.conf
├── Dockerfile
└── docker-compose.yml
```

**Конкурентность:** `asyncio.Lock` на сервер (создание) и на комнату (вход, выход, удаление, владелец). Удаление это
`asyncio.Task`, он отменяется при входе и перед удалением ещё раз проверяет, что комната пуста.

**После перезапуска:** записи о несуществующих каналах удаляются, пустые комнаты чистятся, отсутствующие владельцы
заменяются (если включена автопередача), пропавшие сообщения панели отправляются заново.

## 🐘 PostgreSQL вместо SQLite

```bash
pip install asyncpg
```

```env
DATABASE_URL=postgresql+asyncpg://user:password@host:5432/dbname
```

Код менять не нужно, весь доступ к базе идёт через async-репозитории SQLAlchemy.

## 🩺 Решение проблем

| Симптом | Причина и решение |
|---|---|
| `4014 Disallowed intent(s)` / `PrivilegedIntentsRequired` | Включите **Server Members Intent** в Developer Portal → Bot |
| `LoginFailure` / неверный токен | Сбросьте токен в Developer Portal и обновите `.env` |
| Команд `/setup` нет | Пригласите бота со scope `applications.commands`, подождите пару минут |
| Комната не создаётся | Проверьте права бота и `docker compose logs bot` (строка `bot lacks permissions`) |
| Панели нет в чате комнаты | Боту нужны Send Messages, Embed Links и Read Message History на категории |
| `permission denied` на `data` в Docker | `sudo chown -R 1000:1000 data` |
| Предупреждения про PyNaCl / davey | Безвредны, бот не воспроизводит звук |

## 🔐 Безопасность

- Токен хранится только в `.env` (он в `.gitignore`), никогда не коммитьте его и не вставляйте в `.env.example`.
- Если токен попал в git, чат или скриншот, сразу сбросьте его в Developer Portal.
- Владелец комнаты не получает административных прав, все действия проверяются на сервере при каждом нажатии.
